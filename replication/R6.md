# R6 reproduction

Run from the repository root with Python 3.11 or later:

```sh
python src/r6_benefits.py --check
python -m unittest discover -s tests -p test_r6.py -v
python replication/check_repository.py
```

The numerical generator uses the standard library and does not download anything by default. It validates R2/R4 upstream output hashes before deriving eight CSVs and the R6 validation record. `--check` compares exact bytes without rewriting existing results. Input hashes, source URLs and PDF hashes remain separate. Null/blank fields are unidentified quantities, not zero. The four target cases and two liquid-share choices are sensitivities, not statistical bounds.

With Poppler `pdftotext` and the two pinned public MoF PDFs in their manifest paths:

```sh
python src/r6_benefits.py --verify-sources --check
```

This checks both hashes, the 2021 and 2026 numeric terms on physical pages 5/6 of the monthly report and coupon frequency on physical page 2 of the offering terms. To acquire missing PDFs, add `--acquire`. Retrieval is bounded to 20 MB per source, checks the expected SHA-256 before saving, and refuses changed provider bytes or an already changed cache. It does not replace earlier vintages or redistribute the offering circular. If a pinned source becomes unavailable, retain the lock and report the failure; do not relabel an updated document as the old source. The report's exact publication day is unknown; its document month and original issue dates are recorded separately.

For the figure, install `matplotlib==3.10.8` and run:

```sh
python src/r6_figures.py --check
```

The SVG has a fixed hash salt and no date metadata. The generator reads committed numerical tables; it performs no estimation. SVG bytes can differ under other plotting versions or font installations. CSV checking is independent of plotting. `--preview tmp/r6_preview.png` optionally creates a local raster preview. The committed SVG was visually checked for labels, units and curve endpoints.

## Meaning of outputs

| File | Rows / interpretation |
|---|---|
| `hazard_thresholds.csv` | 135: five funding mechanisms × three FX changes × three losses × three resource-cost sensitivities; required annual probability change |
| `severity_thresholds.csv` | 45: five mechanisms × three FX changes × three chosen annual probabilities; required loss reduction conditional on crisis |
| `joint_liquidity.csv` | 264: 22 dates × three cumulative horizons × four stress assumptions; horizons and scenarios never summed |
| `liquidity_service_curves.csv` | End-2025 12-month schedules; chosen additional drains plus exact transition points, two liquid shares; coverage quantities, no assigned welfare value |
| `historical_sales_scale.csv` | Three complete-window maxima in 2020–2024, excluding the evaluation episode; no crisis-frequency estimate |
| `target_sensitivity.csv` | Four static end-2025 translations; denominator held fixed, funding closure hypothetical |
| `financing_and_model_channels.csv` | USD 100m increment plus four target increments; five-year issuer proceeds/cost PV and separate one-year loss-channel calculations |
| `issuance_comparison.csv` | Original terms from different pricing dates; no causal attribution |
| `validation.json` | Input and numerical output hashes; unidentified policy effect and optimum explicitly null |

In the financing table, `cost_5y_pv_usdm` and `conditional_issuance_proceeds_gain_usdm` compare present values on the five-year bond horizon; `annual_cost_usdm` is a one-year flow. The isolated dollarization loss is conditional on a crisis and its expected value is explicitly annual. They must not be added. A blank break-even yield reduction means the positive cost exceeds the gain available even under the chosen zero-spread floor; it does not mean that all reserve benefits are zero.

Focused tests independently check terminal asset/liability arithmetic, probability units, single-use liquidity and saturation, bond pricing via a closed-form annuity, inversion and spread floor, monthly-window gaps and purchase offsets, the existing R2 finite-difference loss formula, exact output reproduction and source-hash rejection. The repository report also checks all archived evidence and the existing R0–R5 suite. These checks certify computation under assumptions; they do not certify causal identification.
