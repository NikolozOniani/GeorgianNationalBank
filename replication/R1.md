# Reproduce the R1 accounting checkpoint

The [R1 report](../reports/r1_2026_11_10/README.md) is an economic accounting result. This file contains the separate technical procedure. R1 neither changes the registered window nor estimates causal effects.

## Output-only verification

Python 3.11 or later, standard library only:

```sh
python replication/check_repository.py --report replication/local-results/repository_validation.json
```

This checks current and retained legacy tests, all archived hashes, definitions and links. The six additional R1 tests protect the gross/net distinction, absent event dates, quarter-frequency bridges, gold discrepancy, liquidity/cash-accrual identities and the open G1 status. Passing these tests does not prove recovery of original source files.

## Pinned-source reproduction

Install the existing [acquisition dependencies](requirements-acquisition.txt). Restore the original November 9 raw sources using the [source-recovery instructions](ACQUISITION.md). Preserve their locked hashes; a revised remote workbook is a new vintage, not a replacement for an old input. R1 verifies the hashes of all 36 original derived tables and every raw source used in its 49-source register.

Acquire the three additional public documents:

```sh
python src/acquire_r1.py
```

The separate [source plan](../research/r1_source_plan.json) downloads to ignored `data/raw/r1_2026_11_10/`. The committed [manifest](../data/r1_source_manifest.json) pins the acquired bytes. Subsequent retrieval attempts use those pins and write their status to ignored `replication/local-results/r1_retrieval.json`, leaving the original manifest unchanged. Per-source failures are recorded without discarding independent successes. A changed or inaccessible source blocks that part of reproduction rather than silently replacing its checksum. No external source is contacted by the accounting generator itself.

```sh
python src/r1_accounts.py --check
```

The generator builds all 17 CSVs and associated metadata in a temporary directory, performs 124 computational checks and requires byte equality with committed generated outputs. Without `--check` it regenerates only `reports/r1_2026_11_10/` computational outputs; documentation and earlier vintages are not overwritten. Use `--check` for routine verification. Never refresh input locks merely to make changed sources pass.

Manual PDF extraction choices are explicit in `annual()` in [the generator](../src/r1_accounts.py): source ID, PDF page, year, unit, exact numeric anchor and approximation flag. Automated anchor checks guard against absent figures but are not a substitute for inspecting table headings/columns. CSV source locators retain sheet/row/cell references; audit financial figures use PDF pages. All unobserved dates and components serialize as blanks, never invented zeros.

`validation.json` distinguishes computational success from economic/source completeness. The gold discrepancy and other unresolved qualifications remain in `discrepancy_register.json`. Reproduction must retain them. No successful software run changes G1 from partial to complete.
